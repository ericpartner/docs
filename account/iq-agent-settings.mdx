The IQ agent settings help IQ understand your company. Today you can add your company websites.

Go to **Settings → Configuration → IQ**.

<Info>
  Only Owners and Co-Owners can open Settings.
</Info>

## Company websites

Add the public websites of your company. IQ scans them and stores what it finds as account context. IQ then uses that context when it makes suggestions.

IQ suggests and a person decides. Nothing IQ writes from your websites takes effect as a decision. You can read and edit your account context at any time.

### What happens to your account context

- If your account context is empty, IQ fills it with a summary of what it finds.
- If your account context already has text, IQ never overwrites it. IQ adds its findings in a separate section headed **From company websites**.
- If a scan finds more than fits, IQ summarizes it to stay within the 5,000-character limit.
- Removing a website doesn't remove or rewrite context IQ already stored.

### Website status

Under each website, a short note shows what IQ is doing with it:

| Note | What it means |
| --- | --- |
| **IQ is reading this website.** | The scan is running. |
| **IQ could not read this website.** | IQ couldn't open the site. This isn't an error on your side. Check the address, or add a different page. |
| **Last scanned** and a date | IQ read the website on that date. |

The status is up to date when you open the tab. Reopen it to see a newer status.
