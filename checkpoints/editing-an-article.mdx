---

When a checkpoint's microlearning is an **Article**, you write it in exIQtive's built-in rich text editor. This page covers opening the editor and using each of its tools.

## Opening the editor

<Steps>
  <Step title="Open the checkpoint">
    Open the checkpoint you want to work on.
  </Step>
  <Step title="Take the edit lock">
    Click **Edit**, or **Lock to Edit** if the checkpoint is already Active.
  </Step>
  <Step title="Select the Article tab">
    In the Microlearning section, select the **Article** tab. You'll see a blank canvas with the placeholder text *"Start typing, or press '/' for commands…"*
  </Step>
</Steps>

## Typing and basic formatting

Start typing to add plain text. To format text you've already written, select it and use the toolbar that pops up above your selection:

- **Bold**, *Italic*, and ~~Strikethrough~~
- **Text color**: pick a color, or **Clear** to remove it
- **Background color**: the same colors, applied as a highlight
- **Comment**: comment on the selected text (only when commenting is enabled for that checkpoint)

## Adding content with the "/" menu

For headings, lists, images, tables, links, and more, type **/** on a new or empty line. A menu appears where you can search or scroll:

| Option | What it inserts |
| --- | --- |
| **Heading 1, 2, 3** | Section headings |
| **Bullet List**, **Numbered List** | Lists |
| **Task List** | A checklist with checkboxes |
| **Quote** | A blockquote |
| **Divider** | A horizontal rule |
| **Table** | A 3×3 table with a header row |
| **Link** | A link (see below) |
| **Image** | An image (see below) |
| **YouTube** | An embedded YouTube video, by URL |
| **Date** | A date |
| **Equation**, **Math Formula** | Block and inline math |

Underline, Code, and Highlight are also in the menu.

<Tip>
Keep typing after the **/** to filter the menu. For example, `/tab` jumps straight to **Table**.
</Tip>

## Adding a link

Type **/** and choose **Link**. Enter a URL, and the editor inserts linked text. Select the text and type over it to rename it.

## Adding an image

Type **/** and choose **Image** to open the Insert Image window:

- **From computer**: pick a file to upload
- **From URL**: paste a link to an image that's already online

You can also drag an image file from your computer straight onto the editor. A "Drop to upload image" overlay appears while you drag.

## Working with tables

Type **/** and choose **Table** to insert a 3×3 starter table with a header row. Click into any cell to edit it. While your cursor is in a table, a table toolbar lets you:

- Add or delete a row or column
- Merge or split cells
- Turn the header row on or off
- Delete the whole table

## Mentioning a colleague

Type **@** followed by a name to search for and mention a colleague. This isn't available while several people are co-editing the same article.

## Undo and redo

| Action | Windows | Mac |
| --- | --- | --- |
| Undo | **Ctrl+Z** | **Cmd+Z** |
| Redo | **Ctrl+Shift+Z** | **Cmd+Shift+Z** |

<Note>
There's no undo or redo button in the editor; use the keyboard shortcuts.
</Note>

## Saving your work

The edit bar above the editor has two actions:

- **Save**: saves your draft. You stay in edit mode and keep the lock.
- **Exit Edit**: leaves edit mode and releases the lock so others can edit.

<Warning>
Click **Save** before **Exit Edit** if you want to keep unsaved changes.
</Warning>

If the checkpoint is already Active, you'll see **Propose Changes** to start a new draft revision, and **Publish** once your edits are ready to go live. See [Editing a checkpoint](/checkpoints/editing-a-checkpoint).
