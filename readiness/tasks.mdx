A **task** is a single piece of work an administrator assigns to an employee. Every task shows who assigned it and when.

Three task types are available:

| Task | What the employee does |
| --- | --- |
| **Upload video** | Uploads a video for a checkpoint. |
| **Task** | A simple to-do. The employee marks it done. |
| **Register QR code** | Enters a QR code for a checkpoint's video. |

A task is **To Do**, **Completed**, or **Canceled**. Canceled tasks look different from Completed ones, so a cancellation is never mistaken for success.

## Your tasks

Every employee with access to the account can see the tasks assigned to them. Go to **Your Stuff → Your Tasks**.

- The list shows only tasks assigned to you, newest first, 20 per page.
- The status filter starts on **To Do**. Choose **Completed** or **Canceled** to see those.
- Search by task summary. Changing the filter or search takes you back to page 1.
- Each row shows the task type, summary, who assigned it and when, the status, any deadline, and the action for that task.
- Select the chatter icon on a row to open the task's read-only activity history.

If you have no tasks, you see "You currently have no Tasks." If a filter matches nothing, you see "No tasks found" with a **Clear search / filter** action.

### Complete a task

Complete a task from its row:

- **Upload video:** select **Upload**, then choose your video. When the upload finishes, the task becomes Completed.
- **Task:** select **Mark Done**. The task completes right away, with no confirmation.
- **Register QR code:** select **Register**, type the QR code, and submit. The code is required. On the mobile app, you scan the code with the camera instead.

Employees can't edit or cancel tasks. Only an administrator can cancel a task.

## All tasks (administrators)

**All Tasks** is a main-menu item for administrators. It shows every task in the account, across all employees.

- Tasks are listed newest first, 10 per page.
- Filter by **status**, **assignee**, **task type**, **responsibility**, and **deadline** (before or after a date). Filters combine, and search by summary also applies.
- Select **Cancel** on an open task to cancel it. You confirm first, and the prompt shows the task, the assignee, and the checkpoint. Canceling can't be undone.
- If a task is assigned to you, its completion action also appears on the row, next to **Cancel**.

## When tasks are canceled automatically

- Open Upload video and Register QR code tasks are canceled if their checkpoint is deleted.
- All of a person's open tasks are canceled if their access is revoked.

## Notifications

Employees get an email when a task is assigned to them and when it's completed. See [Email notifications](/account/email-notifications).
