IQ is exIQtive's organizational intelligence agent. It works across all the [modules](/concepts/modules), so you meet the same agent whether you're modeling your organization, certifying readiness, or setting pay ranges.

## IQ suggests and a person decides

IQ makes suggestions. You review them, change what you want, and decide. Nothing IQ suggests takes effect until a person accepts it.

Two rules follow from this:

- **IQ never issues a badge.** Only a Coach can issue a badge, after inspecting the employee. See [The badge ladder](/user-guide/readiness/badge-ladder).
- **IQ never scores an employee's performance.** IQ can suggest a score for a person to review, but it never scores the performance of an individual.

## What IQ does in each module

| Module | What IQ does |
| --- | --- |
| [Readiness](/readiness/overview) | Suggests checkpoints to help an Architect build and refine an Inspection Protocol. |
| [Fair Base Pay](/fair-pay/overview) | Suggests a minimum and a maximum for a pay range. You review them before you save. |

IQ works in every module, and the list grows as modules ship. See [Modules](/concepts/modules) for what's available and what's coming soon.
